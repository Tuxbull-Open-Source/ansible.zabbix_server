# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security-advisory reporting for this repository.

Include the affected role revision, impact, reproduction conditions, and a
minimal sanitized example. Do not include real credentials, PSKs, hostnames,
addresses, inventories, topology, or logs from a production environment.

## Supported code

Security fixes target the current default branch. Dependency pins are deliberate;
updates require review and validation against the supported Rocky Linux and
Zabbix versions.
